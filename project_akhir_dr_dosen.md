1\. Judul Proyek

“Pengembangan Sistem Informasi Inventaris Barang Berbasis Web Menggunakan PHP dan MySQL”

2\. Latar Belakang

Sebuah laboratorium komputer memiliki banyak barang seper! komputer, monitor, printer, proyektor, meja, dan perangkat jaringan. Selama ini pencatatan barang masih dilakukan menggunakan spreadsheet sehingga mengalami beberapa masalah, seper! kesulitan mencari data, duplikasi pencatatan, kesalahan dalam memperbarui stok, dan kesulitan mengetahui kondisi barang.

Mahasiswa diminta mengembangkan sistem informasi inventaris berbasis web menggunakan PHP dan MySQL untuk membantu pengelolaan data barang secara lebih terstruktur.

3\. Pertanyaan/Masalah Utama

Bagaimana merancang dan membangun sistem informasi inventaris barang berbasis web yang dapat membantu pengguna melakukan pengelolaan data barang secara efek?f dan efisien?
